# Joud Mutlaq — Project Portfolio

Static portfolio built for GitHub Pages.

## Structure

- `index.html` — page structure
- `styles.css` — visual system and responsive layout
- `projects.js` — project data (add future projects here)
- `script.js` — rendering, modal case studies, interactions
- `assets/` — project images
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing to this static site

## Add a future project

Open `projects.js`, duplicate one project object, update its text/images/links, and save. The homepage will automatically render the new card.
